# Hero-изображения для страниц сайта

## Общая настройка серии

Для каждой генерации приложить 2–3 лучших изображения из папки `генерации` как **референсы стиля**, а не как объекты для копирования.

**Формат:** 2048×1152 px, 16:9. Важные объекты держать в центральных 70% кадра, чтобы изображение безопасно кадрировалось на телефоне. Для страниц с текстом поверх фона оставлять спокойную, менее детализированную область слева. Без надписей, вывесок крупным планом, логотипов и водяных знаков.

**Общий стиль серии:** тёплая атмосферная иллюстрация санатория на основе реальной архитектуры и интерьеров; мягкая живописная фактура, естественные пропорции, спокойная зелёно-бежево-медовая палитра, рассеянный дневной свет, ощущение заботы, чистоты и тишины; единая цветокоррекция и степень детализации во всей серии. Не превращать сцену в люксовый SPA-отель и не добавлять оборудование или помещения, которых нет в исходных материалах.

## Промты по страницам

### Главная `/`

Use case: stylized-concept. Asset type: website hero. Главный корпус санатория «Звездный» среди взрослых сосен, ухоженная дорожка ведёт к входу, несколько гостей неспешно идут по территории, мягкий утренний свет и лёгкая дымка. Широкий общий план, архитектура справа и в центре, спокойная область слева под заголовок. Сохранить общий стиль серии; без текста, логотипов, автомобилей на переднем плане и курортной роскоши.

### О санатории `/about`

Use case: stylized-concept. Asset type: website hero. Просторная лесная территория санатория с корпусом, дорожками, лавочками и солнечными пятнами под кронами; акцент на масштабе территории и связи архитектуры с природой. Панорамный план, глубина через дорожку, спокойная область слева. Без фантазийных построек и чрезмерно декоративного ландшафта.

### Лечение `/treatment`

Use case: stylized-concept. Asset type: website hero. Светлый кабинет санаторного лечения: врач спокойно обсуждает с взрослым гостем индивидуальный план восстановления, на втором плане аккуратное реальное оборудование, растения и окно с видом на сосны. Уважительная дистанция, без читаемых медицинских документов, инъекций и пугающих деталей; герои справа, свободное место слева.

### Процедуры `/procedures`

Use case: stylized-concept. Asset type: website hero. Современный светлый процедурный кабинет санатория, медицинская сестра готовит безопасную физиотерапевтическую процедуру для взрослого гостя; оборудование основано на референсах, атмосфера спокойная и профессиональная. Средне-широкий план, действие справа, слева чистая визуальная зона; без хирургии, игл и вымышленных аппаратов.

### Врачи `/doctors`

Use case: stylized-concept. Asset type: website hero. Небольшая команда санатория — врач и медицинская сестра — в светлом кабинете обсуждают маршрут лечения, естественные доброжелательные выражения лиц, профессиональная одежда без читаемых бейджей. Герои справа, кабинет и мягкий дневной свет поддерживают доверие; не делать рекламный групповой портрет и не копировать личность реального сотрудника.

### Проживание `/stay`

Use case: stylized-concept. Asset type: website hero. Реальный светлый номер санатория, аккуратно застеленная кровать, натуральные материалы, окно с видом на сосновую территорию, небольшой стол и необходимая бытовая мебель по референсам. Широкий интерьерный кадр, без людей, слева менее контрастная зона; не превращать номер в пятизвёздочный отель.

### Перед заездом `/prepare`

Действие справа, свободная зона слева; без очередей, чемоданных гор и аэропортной эстетики.

### ОМС и цены `/oms`

Use case: stylized-concept. Asset type: website hero. Сотрудник санатория за аккуратной стойкой помогает взрослому гостю разобраться с документами и условиями путёвки, бумаги без читаемого текста, открытая доброжелательная сцена в реальном фойе. Композиция справа, спокойный фон слева; без денег, банковских карт крупным планом и государственных эмблем.

### Официальная информация `/official`

Главная группа справа, свободная зона слева; без сцены с текстовыми баннерами и массовой толпы.

### Контакты `/contacts`

Use case: stylized-concept. Asset type: website hero. Подъезд и главный вход санатория, хорошо читаемый маршрут по дорожке, мягкий дневной свет, один прибывающий гость у входа; изображение должно помогать мысленно найти место. Вход справа, пространство слева; без карт, указателей с нечитаемыми надписями и автомобилей крупным планом.

### Фотогалерея `/gallery`

Панорама с глубиной, главный акцент справа, слева место под текст; без коллажа и фоторамок.

### Персональные данные `/privacy`

Use case: stylized-concept. Asset type: website hero. Спокойная административная сцена: закрытая папка, ноутбук без видимого экрана и аккуратное рабочее место сотрудника санатория, ощущение конфиденциальности и порядка. Предметы справа, мягкая область слева; без замков, киберпанка, читаемых данных и документов.

### Доступная среда `/accessibility`

Use case: stylized-concept. Asset type: website hero. Доступный вход в санаторий с пологим пандусом, поручнями и широкой дорожкой, взрослый гость на коляске рядом с сопровождающим движется ко входу естественно и самостоятельно. Архитектура и люди справа, место слева; без чрезмерного акцента на инвалидности и без элементов, которых нет на реальном объекте — сверить с фото.

Гость санатория беседует с сотрудником в светлом фойе, открытая поза, внимательное отношение и спокойная обратная связь; никаких анкет с читаемым текстом. Герои справа, свободный фон слева; без жеста «палец вверх», рейтинговых звёзд и рекламной постановки.

### Противодействие коррупции `/anti-corruption`

Use case: stylized-concept. Asset type: website hero. Строгое, но спокойное административное рабочее место санатория: аккуратно разложенные нейтральные документы, открытое пространство, дневной свет, ощущение прозрачности процедур. Объекты справа, свободная зона слева; без денег, наручников, судейских молотков, гербов и буквального криминального сюжета.

## Контроль перед использованием

1. Сравнить архитектуру, мебель и оборудование с исходными фото.
2. Проверить единый цвет, фактуру и детализацию всей серии.
3. Проверить читаемость белого текста на затемнённом слое сайта.
4. Проверить кадрирование на 1440×900, 768×1024 и 390×844.
5. Не публиковать изображения с узнаваемыми реальными людьми без согласия.
