# Проект сайта санатория "Звездный"

Дата фиксации состояния: 4 июля 2026.

## Цель проекта

Сайт ГАУЗ Калужской области "Калужский санаторий "Звездный" развивается из лендинга в многостраничный информационный сайт госмедучреждения.

Главный фокус не на бронировании, а на понятном информировании:

- что представляет собой санаторий;
- кому подходит санаторно-курортное лечение;
- какие есть программы, профили, процедуры и специалисты;
- как устроены проживание, питание, досуг и подготовка к заезду;
- где найти официальные документы, лицензии, цены, графики и сведения об учреждении.

## Текущий стек

- React + TypeScript + Vite.
- Самодельная SPA-навигация без роутера.
- Базовый путь Vite: `/sr/`.
- Основные файлы:
  - `src/App.tsx` - структура страниц, навигация, общие компоненты;
  - `src/content.ts` - контентные данные сайта;
  - `src/styles.css` - вся визуальная система и адаптив;
  - `public/docs` - официальные документы, которые отдаются сайтом.

## Технические нюансы

- Vite настроен с `base: '/sr/'`, поэтому локальный адрес разработки: `http://127.0.0.1:5173/sr/`.
- Для сборки использовать `npm.cmd run build`, так как в PowerShell может мешать execution policy для `npm.ps1`.
- Dev-сервер запускался командой:

```powershell
npm.cmd run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

- В PowerShell русские строки иногда отображаются кракозябрами, но файлы в UTF-8 и в Node читаются корректно.
- При `git status` может появляться предупреждение про `C:\Users\usjei/.config/git/ignore: Permission denied`; оно не блокирует работу.
