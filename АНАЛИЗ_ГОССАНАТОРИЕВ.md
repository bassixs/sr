# Анализ сайтов государственных и ведомственных санаториев

Дата анализа: 06.07.2026.

Цель: понять, какие разделы и данные повторяются у похожих санаториев, чтобы доработать сайт ГАУЗ Калужской области "Калужский санаторий "Звездный" не наугад, а по реальным паттернам.

## Что смотрелось

1. ФГБУ "Санаторий "Волжский утес имени академика Е.И. Чазова" Управления делами Президента РФ.
2. ФГБУ "Объединенный санаторий "Сочи" Управления делами Президента РФ.
3. ФГБУ "Объединенный санаторий "Подмосковье" Управления делами Президента РФ.
4. ФГБУ "Объединенный санаторий "Русь" Управления делами Президента РФ.
5. ФГБУ "Клинический санаторий "Барвиха" Управления делами Президента РФ.
6. ФГБУ "Санаторий "Дубовая роща" Управления делами Президента РФ.
7. ФГБУ "Санаторий "Заря" Управления делами Президента РФ.
8. ФГБУ "Санаторий "Красные камни" Управления делами Президента РФ.
9. ФГБУ "Санаторий "Загорские дали" Управления делами Президента РФ.
10. Санаторий "Россия", Белокуриха, как сильный коммерческий/медицинский референс по упаковке лечения, специалистов и правовой информации.

Дополнительно сверялась структура подведомственных санаторно-курортных организаций Управления делами Президента РФ и открытые карточки организаций.

## Главная закономерность

У хорошего сайта санатория есть два разных слоя:

1. **Гостевой слой**: быстро объясняет, кому подходит санаторий, какие есть программы, лечение, процедуры, проживание, питание, отдых, дети, подготовка к заезду.
2. **Официальный слой**: сухо и полно закрывает требования медорганизации и госучреждения: сведения об учреждении, лицензия, режим работы, руководство, структура, реквизиты, платные услуги, права пациента, персональные данные, антикоррупция, СОУТ, доступная среда, контролирующие органы.

Для "Звездного" нужно не смешивать эти слои. Сейчас сайт уже движется в эту сторону, но официальный слой стоит сделать более системным.

## Что повторяется у сильных примеров

### 1. Отдельная страница "Сведения об учреждении"

Обычно содержит:

- полное и сокращенное наименование;
- учредителя;
- ОГРН, ИНН, КПП;
- адрес;
- режим работы;
- телефоны по отделам;
- email;
- руководителя;
- лицензию;
- перечень работ/услуг по лицензии;
- способы оплаты;
- ссылки на документы.

У "Волжского утеса" это оформлено отдельным PDF "Информация об учреждении": там есть наименование, учредитель, ОГРН, ИНН, режим 24/7, телефоны приемной, бухгалтерии, размещения, продаж, способы оплаты, адрес, email, номер лицензии, дата, орган выдачи и длинный перечень услуг по лицензии.

### 2. Контакты делятся по задачам

Не один общий телефон, а:

- приемная директора;
- отдел размещения;
- отдел продаж / бронирования;
- бухгалтерия;
- факс;
- общий email;
- отдельные email для бронирования/приемной, если есть.

Для "Звездного" сейчас есть общий телефон, дополнительный телефон и факс, но стоит запросить у администрации разметку по задачам: приемная, регистратура/путевки, бухгалтерия.

### 3. Лечение раскрывается не одной страницей

Частый набор:

- лечебные профили;
- программы лечения;
- процедуры / методы лечения;
- природные лечебные факторы;
- показания и противопоказания;
- специалисты;
- документы для заезда.

У "России" в Белокурихе лечение разложено именно так: профили, программы, процедуры, природные факторы, показания/противопоказания, специалисты.

### 4. Врачи оформляются карточками с доказательной информацией

Хорошая карточка специалиста включает:

- фото;
- ФИО;
- должность/специальность;
- образование;
- интернатуру/ординатуру;
- переподготовку;
- квалификационную категорию;
- сведения об аккредитации;
- срок действия аккредитации;
- график работы.

У "России" в Белокурихе карточки специалистов очень подробные: есть образование, категории, переподготовка, аккредитация и график. Для "Звездного" текущая страница с ролями без ФИО — временный вариант, ее нужно будет заменить на реальные карточки.

### 5. Проживание показывается как отдельный продукт

Повторяются:

- категории номеров;
- фото;
- состав номера;
- вместимость;
- что входит;
- для кого подходит;
- кнопка/ссылка на цену или заявку.

На гос/ведомственных сайтах часто есть подробный номерной фонд, количество корпусов, категории, оснащение и доступные номера для людей с ограниченными возможностями.

### 6. Инфраструктура важна не меньше медицины

Повторяются:

- бассейн;
- ЛФК;
- тренажерный зал;
- библиотека;
- бильярд/настольные игры;
- детская комната/площадка;
- прогулочные маршруты;
- экскурсии;
- парковка;
- Wi-Fi;
- досуг и мероприятия.

У "Подмосковья" отдельно перечислены бассейны, тренажерные залы, ЛФК, прокат, мастер-классы, экскурсии, детская комната, Wi-Fi, библиотека, трансфер, парковка и сервисные услуги.

### 7. Правовой раздел обычно шире, чем "документы"

В правовом/прочем разделе встречаются:

- правила пребывания;
- лицензия;
- политика обработки персональных данных;
- согласия;
- права и обязанности пациента;
- памятка о госгарантиях бесплатной медпомощи;
- контролирующие организации;
- договоры/формы договоров;
- положение о возврате денежных средств;
- СОУТ;
- антикоррупционная политика;
- план противодействия коррупции;
- учетная политика / сведения для госучреждений;
- cookie-политика, если есть аналитика/формы.

У "Волжского утеса" в "Прочей информации" есть правила пребывания, СОУТ, учетная политика, корпоративная программа, положение по обработке данных, медицина, видеонаблюдение, антикоррупционная политика, лицензия, планы по коррупции и другое.

### 8. Документы для заезда нужно показывать рядом с подготовкой

Повторяются:

- паспорт / свидетельство о рождении;
- санаторно-курортная карта 072/у, для детей 076/у;
- срок действия карты;
- справка об эпидокружении для детей;
- анализ на энтеробиоз для детей;
- нотариальное согласие для несовершеннолетних без законных представителей;
- правила для иностранных граждан.

Для "Звездного" страницу подготовки к заезду стоит расширить до полноценного чеклиста.

## Что нужно добавить или переработать в "Звездном"

### Приоритет 1. Официальный слой

- Сделать отдельную страницу/блок **"Сведения об учреждении"** внутри `/official`.
- Вывести не только карточки документов, а структурированные данные: наименование, учредитель, адреса, ОГРН, ИНН, КПП, ОКПО, ОКВЭД, руководитель, режим работы, контакты по отделам.
- Добавить текстовый блок лицензии: номер, дата, орган выдачи, статус, адреса деятельности, перечень работ/услуг.
- Добавить "Права и обязанности пациента".
- Добавить "Контролирующие органы".
- Добавить "Платные услуги": порядок, способы оплаты, договор/условия, возврат средств.
- Добавить "Правила пребывания".
- Добавить "СОУТ" и "Антикоррупция" как отдельные документы/подразделы.

### Приоритет 2. Лечение и программы

- Разделить лечение на: профили, программы, процедуры, природные факторы, показания/противопоказания.
- Для программ сделать карточки: кому подходит, длительность, что входит, какие документы нужны, есть ли проживание.
- Для процедур добавить понятные группы: водолечение, физиотерапия, ЛФК, массаж, галотерапия, питьевое лечение, термолечение, диагностика.
- Добавить осторожную медицинскую формулировку: "назначается врачом после осмотра, имеются противопоказания".

### Приоритет 3. Врачи

- Заменить роли на реальные карточки врачей после получения согласий.
- Минимум для карточки: ФИО, должность, образование, квалификация, аккредитация, стаж, график.
- Пока данных нет, оставить страницу как "медицинская команда" без псевдоперсоналий.

### Приоритет 4. Подготовка к заезду

- Расширить страницу до пошагового сценария:
  1. выбрать программу;
  2. уточнить наличие мест;
  3. подготовить документы;
  4. приехать к расчетному часу;
  5. первичный прием врача;
  6. назначение процедур.
- Добавить отдельные списки документов для взрослых, детей и сопровождающих.

### Приоритет 5. Проживание, питание, инфраструктура

- Для номеров сделать карточки категорий, даже если пока без реальных фото.
- Для питания добавить тип питания, кратность, диетические столы/особенности.
- Инфраструктуру показать не россыпью, а группами: лечение, отдых, дети, спорт, сервис.

## Вывод

Сайт "Звездного" нужно развивать как информационный сайт медицинской организации, а не как лендинг бронирования. Главная должна быть спокойной и понятной, а глубина должна уходить в разделы:

- "О санатории";
- "Лечение";
- "Программы";
- "Процедуры";
- "Врачи";
- "Проживание и питание";
- "Подготовка к заезду";
- "ОМС и цены";
- "Официально";
- "Контакты".

Самая важная доработка ближайшего этапа — не дизайн, а структура официальной информации: она должна быть доступна как человеку, так и проверяющим органам.
